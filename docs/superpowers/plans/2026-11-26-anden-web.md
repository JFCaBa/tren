# Andén website (andenapp.com) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** andenapp.com shows every Cercanías/Rodalies station's live board (built by the Andén API) with one crawlable page per station, like whatplatform.uk.

**Architecture:** A Python port of the app's `computeBoard` serves `GET /board/<stop>` from the
Andén API (tren `server/anden_api`), using the timetables it already loads and Renfe's real time
it already holds. A static site (`website/`, ES modules, no build) draws it; `website/build_pages.py`
pre-renders a page per station, the A–Z page, the sitemap, the search list and the legal pages
nightly after the feed. nginx on the same VPS serves andenapp.com and proxies `/api/board/`.

**Tech Stack:** Python 3 stdlib (API runs 3.12 in docker; tests also on the Mac's 3.9 for
`website/`), `unittest`/pytest as each folder uses now, browser ES modules with `node --test`,
nginx, certbot, Cloudflare DNS.

**Spec:** `docs/superpowers/specs/2026-11-26-anden-web-design.md`

**Mirror:** the platform repo (`/Volumes/HIKSEMI/Projects/platform`): `site/` (index.html with
`<!--seo:head|body|extra-->` markers, js/route.js `extraBelongs`, app.js `setMeta`, style.css),
`deploy/web/build_pages.py` + tests (validate, fill, symlink publish, fcntl lock),
`deploy/web/dev.py`, `deploy/nginx/whatplatform.uk.conf` (website server block, 404 shell).
Copy and adapt; never import across repos.

## Global Constraints

- Spanish copy only. Brand teal `#0F766E`, light/dark like `web/privacidad.html`.
- Station URL `/estacion/{stopId}`, stop ids are 5 digits (`^[0-9]{5}$`, all 887 today).
- Board constants as `app/lib/domain/board.dart`: real time max age 2 min, feed max age 3 days,
  60 s grace after departure, service days −1/0/+1 in Europe/Madrid, GTFS time = local noon
  − 12 h + seconds, limit 8, live platform only when `minutes <= 15`, realtime only for trips with
  exactly one date, grey line colour `#9E9E9E`.
- Privacy: nothing personal stored or logged (no IP, User-Agent, hash); `access_log off` and
  `error_log /dev/null crit` on andenapp.com as on whatplatform.uk.
- No framework, bundler or npm dependencies in `website/`.
- No change to the platform repo; no `api.whatplatform.uk/anden/board` route.
- Secrets (contact email/name, admin keys) only on the VPS.

## Review Focus

- Station served by two núcleos (17 stops): trips of both feeds merged, one list by time.
- Around midnight and on DST change days the web must show the same trains and times as the app.
- Renfe down / API idle: page still shows scheduled trains with a "sin tiempo real" note, never an
  error; first request after idle wakes the refresher.
- A stop id with no page (unknown, 4 digits, letters) answers 404 with the shell, never 200.
- Many viewers of one station: one board computation per 15 s; every request still counted.

**Interfaces:**
- Consumes: Task 1 `compute_board`, Task 2 `feeds_for`/`station`, `trips.cached(now, BOARD_RT_MAX_AGE)`
  with its own `BOARD_RT_MAX_AGE = 120` (the app's 2 min; `/live` keeps `LIVE_MAX_AGE = 90`),

- Produces: `GET /board/<stop>` (`BOARD_PATH = ^/board/([0-9]{5})$`) → 200
  `{"generatedAt": ISO now, "station": {...}, ...compute_board fields}`; 404 `{"error":"not found"}`

  from positions whose `stop_id == stop`, `platform` set and observation not older than 120 s
  (`Sighting.at`, else `positions_ts`), as the app's `platformsAt`. Result cached per stop for 15 s
  (`BOARD_TTL = 15`, dict guarded by a lock, entries older than TTL dropped on write). Every
  request (cached or not) calls `count_live`. `stats._version(ua)` returns `"web"` for
  `ua.startswith("Mozilla/")` without `bot|crawl|spider|preview|headless` (case-insensitive),
  counted as a person like app versions.

**Interfaces:** nginx conf, modelled on the platform website block:
- `limit_req_zone $binary_remote_addr zone=anden_board:1m rate=120r/m;` (own zone).
- `server` :80 for `andenapp.com www.andenapp.com` → 301 https (certbot webroot `/.well-known/acme-challenge/` from `/var/www/html`).
- `www.andenapp.com` :443 → 301 `https://andenapp.com$request_uri`.
- `andenapp.com` :443: `root /opt/anden/repo/website`; headers HSTS, nosniff, frame DENY,
  no-referrer, CSP `default-src 'none'; script-src 'self'; style-src 'self'; img-src 'self';
  connect-src 'self'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'`;
  `error_page 404 /404-shell`; `/` index; `~ "^/estacion/([0-9]{5})/?$"` → `/opt/anden/pages/current/estacion/$1.html`
  or 404; `/estaciones`, `/sitemap.xml`, `/stations.json`, `/legal.css`, `~ ^/privacidad/?$`, `~ ^/ayuda/?$`
  from pages/current; `/robots.txt`; css/js no-cache; icons and badge;
  `location ~ "^/api/board/([0-9]{5})$"` GET only, `limit_req zone=anden_board burst=30 nodelay`,
  429, proxy to `http://127.0.0.1:8520/board/$1` with `X-Real-IP $remote_addr`, `X-Forwarded-For ""`,
  timeouts 2 s/5 s, `Cache-Control no-store`; everything else 404.
- feed.sh: `python3 /opt/anden/repo/website/build_pages.py --data "$OUT/current" --site /opt/anden/repo/website --legal /opt/anden/repo/web || echo "$(stamp) pages failed"`.
