# Andén: preparación para las tiendas (plan de implementación)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dejar Andén lista en App Store Connect (ficha completa con el build 8 seleccionado, a falta del "Enviar a revisión" que confirma el usuario) y en Google Play Console (app creada con la prueba cerrada en marcha).

**Architecture:**
- El icono se define en SVG en `tools/icon/`. Chrome headless lo pasa a PNG e ImageMagick saca los tamaños; `flutter_launcher_icons` (solo dev_dependency) genera los recursos de iOS y Android.
- Las páginas legales son plantillas HTML en `web/`. La Action sustituye en ellas el contacto con las variables de repo `CONTACT_EMAIL` y `CONTACT_NAME`, que define el usuario, y las copia a Pages.
- Los textos de las fichas viven en `docs/store/`.
- Las fichas se rellenan en Chrome con las sesiones abiertas del usuario. Los campos de contacto personal los escribe el usuario.

**Tech Stack:** Flutter 3.50, ImageMagick 7 (`magick`), Google Chrome headless, `flutter_launcher_icons` (dev), GitHub Actions/Pages (`envsubst`), `xcodebuild -exportArchive`, Claude in Chrome.

**Spec:** `docs/superpowers/specs/2026-11-16-tiendas-design.md`

## Global Constraints

- Nombre visible: **Andén**. Ficha: "Andén" o, si está cogido, "Andén · Próximo tren". Identificador sin cambios: `com.jfcaba.proximotren`.
- Icono B: fondo `#0F766E`, anillo de fondo `#134E4A`, anillo, tren y detalles en blanco.
- **Datos de contacto personales:** nunca se escriben en ficheros del repo ni en comandos de Claude. Las páginas usan `${CONTACT_EMAIL}` y `${CONTACT_NAME}`, sustituidos en CI desde las variables de repo de GitHub, que crea el usuario con `! gh variable set …`. En los formularios de las tiendas, esos campos los rellena el usuario.
- Gratis, categoría Viajes, para todos los públicos, sin recogida de datos.
- Sin la palabra "Renfe" en el nombre, el subtítulo ni las palabras clave. En la descripción solo aparece como fuente de datos: "app no oficial, sin relación con Renfe".
- Solo iPhone y vertical (ya hecho en `d9fb148`).
- Capturas iPhone: 1320×2868. Capturas Android: ≥ 1080 px de ancho.
- **Nunca** se envía a revisión ni se publica en ninguna tienda sin confirmarlo antes con el usuario en el chat.
- Los commits con código o configuración se validan con `consenso`. Los de solo docs o assets quedan exentos.
